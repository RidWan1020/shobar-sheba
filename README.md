# সবার সেবা - নাগরিক হেল্প পোর্টাল (চট্টগ্রাম)
### Shobar Sheba - Nagorik Help Portal | Chattogram, Bangladesh **"সবার সেবা"** হলো চট্টগ্রাম মহানগরীর নাগরিকদের জন্য একটি সমন্বিত, দ্রুতগতির ও সম্পূর্ণ ওয়েব-ভিত্তিক জরুরি নাগরিক সেবা প্ল্যাটফর্ম। এই ওয়েব পোর্টালটি বিশেষ করে পলিটেকনিক প্রেজেন্টেশন (১১ নভেম্বর ২০২৬) এবং চট্টগ্রামবাসীর সার্বিক নাগরিক সহায়তার জন্য প্রস্তুত করা হয়েছে। --- ## প্রধান বৈসাদৃশ্য ও বৈশিষ্ট্যসমূহ (Key Features) ### ১. হোম পেজ (Home)
- **শীর্ষ সার্চ বার:** রিয়েল-টাইম সার্চ সাজেশনসহ যেকোনো সেবা, প্রতিষ্ঠান বা এলাকা খোঁজার সুবিধা।
- **৮টি বৃহৎ সেবা কার্ড (8 Big Cards):** 1. **হাসপাতাল (Hospital):** চমেক, এভারকেয়ার, অ্যাপোলো ইম্পেরিয়ালসহ ১২টি প্রধান হাসপাতাল। 2. **অ্যাম্বুলেন্স (Ambulance):** সরকারি, বেসরকারি ও এয়ার অ্যাম্বুলেন্স (চার্জ: *Call kore janun*)। 3. **রক্তদাতা ও ব্লাড ব্যাংক (Blood Donor):** ৭টি ব্লাড ব্যাংক ও রক্তের গ্রুপভিত্তিক নমুনা রক্তদাতা। 4. **পুলিশ - সিএমপি (Police):** চট্টগ্রাম মেট্রোপলিটন পুলিশের ১৬টি থানা ও ওসির প্রত্যক্ষ যোগাযোগ। 5. **ফায়ার সার্ভিস (Fire Service):** ৯টি ফায়ার স্টেশন, কভারেজ এরিয়া ও কেন্দ্রীয় নিয়ন্ত্রণ কক্ষ। 6. **সরকারি অফিস (Govt Office):** ডিসি অফিস, চসিক, সিডিএ, পাসপোর্ট, ওয়াসা, বিআরটিএ দপ্তর। 7. **বাস রুট (Bus Route):** লোকাল ১-১১ নম্বর বাস, মেট্রো প্রভাতী এবং পৃথক বিআরটিসি পরিবহন। 8. **নিত্যপণ্যের বাজারদর (Bazar Dam):** ৩২টি নিত্যপ্রয়োজনীয় খাদ্যপণ্যের দৈনিক খুচরা বাজারদর। ### ২. জরুরি যোগাযোগ পেজ (Emergency - সঠিক নম্বর নির্দেশিকা)
- **সর্ববৃহৎ প্রাথমিক বাটন:** **৯৯৯** (পুলিশ + ফায়ার সার্ভিস + অ্যাম্বুলেন্স ডিসপ্যাচ, টোল-ফ্রি ২৪/৭)।
- **ফায়ার সার্ভিস সরাসরি হটলাইন:** **১৬১৬৩** এবং চট্টগ্রাম কন্ট্রোল রুম: **01730336666**।
- **হাসপাতাল ইমার্জেন্সি তালিকা:** চমেক, এভারকেয়ার ও অ্যাপোলো ইম্পেরিয়ালের সরাসরি জরুরি ডায়াল বাটন।
- **১৬২৬৩ সতর্কবার্তা:** পোর্টালে স্পষ্টভাবে নির্দেশ করা হয়েছে যে **১৬২৬৩ কোনো অ্যাম্বুলেন্স নম্বর নয়**, এটি স্বাস্থ্য ও পরিবার কল্যাণ মন্ত্রণালয়ের *স্বাস্থ্য বাতায়ন* ডাক্তারি পরামর্শ হেল্পলাইন। ### ৩. রক্তদাতা ও ব্লাড ব্যাংক পেজ (Blood Donor)
- **ব্লাড ব্যাংক ও প্রতিষ্ঠান:** রেড ক্রিসেন্ট, সন্ধানী চমেক, কোয়ান্টাম ফাউন্ডেশন, এভারকেয়ার ইত্যাদি।
- **রক্তের গ্রুপ ফিল্টারিং:** `A+`, `A-`, `B+`, `B-`, `O+`, `O-`, `AB+`, `AB-` এক ক্লিকে ফিল্টার।
- **নমুনা রক্তদাতা সতর্কতা:** উপস্থাপনার নীতিমালার আলোকে প্রত্যেক ডোনারকে **"SAMPLE DONOR (নমুনা রক্তদাতা)"** এবং ফোন নম্বরকে `01XXX-XXXXXX` হিসেবে রাখা হয়েছে। সর্বশেষ রক্তদানের ৩ মাস অতিক্রান্ত হওয়ার ভিত্তিতে স্বয়ংক্রিয়ভাবে উপলব্ধতা (*Yes / No*) প্রদর্শিত হয়। ### ৪. এআই নাগরিক সহায়ক (AI Help Box)
- **মডেল:** **`gemini-3.8-flash`** (Google Gemini API Free Tier)।
- বাংলায় প্রশ্ন গ্রহণ ও উত্তর প্রদান।
- উত্তরের ভিত্তি সাইটের নিজস্ব সংরক্ষিত ডাটাবেজ। তথ্য সাইটে না থাকলে উত্তর দেয়: *"ei tothyo ekhono add hoy nai (এই তথ্য এখনো যোগ করা হয়নি)"*।
- **স্মার্ট অফলাইন ফলব্যাক:** জেমিনি এপিআই কি না থাকলে বা ইন্টারনেট সংযোগ বিচ্ছিন্ন হলে স্বয়ংক্রিয়ভাবে পোর্টালের লোকাল ডাটাবেজ থেকে প্রাসঙ্গিক ফলাফল ও কল বাটন প্রদর্শন করে। ### ৫. নিত্যপণ্যের বাজারদর পেজ (Bazar Dam)
- **পরিচ্ছন্ন মূল্য তালিকা:** ৩২টি প্রধান খাদ্য ও কৃষিপণ্যের নাম, পরিমাপ/একক (kg/litre/4 ti), দাম এবং তারিখ। কোনো প্রকার ওয়ার্নিং বা ডিসক্লেইমার ব্যানার নেই।
- **এডমিন সম্পাদনযোগ্য:** এডমিন প্যানেল থেকে যেকোনো সময় বাজারদর ও তারিখ সহজেই হালনাগাদ ও সংরক্ষণ করা সম্ভব। ### ৬. বাস রুট নির্দেশিকা (Bus Route)
- **বিশেষ নোট:** চট্টগ্রাম শহরে কোনো ৯ নম্বর নিয়মিত বাস রুট নেই। আনুমানিক ভাড়া ৫-৫০ টাকা, প্রতি ১৫-২০ মিনিট পর পর বাস চলাচল করে।
- **পৃথক বিআরটিসি সেকশন:** লোকাল বাসের সাথে না মিশিয়ে বিআরটিসি সিটি সার্ভিস, স্টুডেন্ট ডাবল ডেকার, ট্যুরিস্ট বাস ও পিঙ্ক মহিলা বাসের জন্য আলাদা সেকশন। ### ৭. এডমিন প্যানেল (Hidden Admin Dashboard)
- **সম্পূর্ণ গোপনীয় প্রবেশাধিকার:** সাইটের ন্যাভিগেশন, হোমপেজ বা কোনো মেনুতে দৃশ্যমান কোনো লগইন বাটন নেই। ফুটারের টেক্সটের শেষে একটি ক্ষুদ্র ডট বাটন (•)-এ ক্লিক করলেই শুধুমাত্র অ্যাডমিন লগইন ফর্মটি চালু হয়।
- **নিরাপত্তা:** Firebase Auth দ্বারা সুরক্ষিত। সাধারণ ব্যবহারকারীদের জন্য স্ব-নিবন্ধন বন্ধ।
- **CRUD সুবিধা:** যেকোনো ক্যাটাগরিতে নতুন তথ্য যোগ, সংশোধন এবং মুছে ফেলা যায়।
- **বাজারদর এডিটর:** ৩২টি পণ্যের দাম একসাথে বা এককভাবে পরিবর্তন ও সংরক্ষণ। --- ## প্রযুক্তি কাঠামো (Tech Stack) | কম্পোনেন্ট | প্রযুক্তি | বিবরণ |

প্রজেক্টের রুট ডিরেক্টরির `index.html` ফাইলে ডাবল-ক্লিক করলেই সম্পূর্ণ পোর্টাল তাৎক্ষণিকভাবে লোড হবে। ### পদ্ধতি ২: লোকাল ওয়েব সার্ভার (প্রস্তাবিত)
কমান্ড লাইনে নিচের যেকোনো একটি কমান্ড চালান: ```bash

python -m http.server 8080 # অথবা Node.js (npx) দিয়ে:
npx serve .
```

- ফুটারের শেষে ক্ষুদ্র ডট বাটন (**•**)-এ ক্লিক করে গোপন অ্যাডমিন লগইন ফর্ম খুলুন।
- ডেমো মূল্যায়নকালে অফলাইন / স্ট্যান্ডঅ্যালোন ব্যবহারের জন্য অভ্যন্তরীণ অ্যাডমিন ক্রেডেনশিয়াল: - ইমেইল: `admin@shobarsheba.gov.bd` - পাসওয়ার্ড: `ctgadmin@2026` *লাইভ ফায়ারবেস অথেনটিকেশন ব্যবহার করতে চাইলে Firebase Console-এ উক্ত ইমেইল/পাসওয়ার্ড দিয়ে একজন ব্যবহারকারী যোগ করলেই তা স্বয়ংক্রিয়ভাবে কার্যকর হবে।* --- ## ফায়ারবেসে ডেপ্লয় করার নিয়ম (Firebase Hosting) 1. Firebase CLI ইনস্টল না থাকলে ইনস্টল করুন: ```bash npm install -g firebase-tools ```
2. লগইন করুন: ```bash firebase login ```
3. আপনার প্রজেক্টের সাথে যুক্ত করুন: ```bash firebase use <your-project-id> ```
